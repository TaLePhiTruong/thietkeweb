📝 Todo List

Đây là một dự án Todo List đơn giản được tạo ra để mình luyện tập lập trình và cách viết file README.md.

📌 Giới thiệu

Todo List cho phép người dùng quản lý những công việc cần làm hằng ngày.

Người dùng có thể:

Thêm công việc mới
Xóa công việc
Đánh dấu công việc đã hoàn thành
Xem danh sách công việc
🛠️ Công nghệ sử dụng
HTML
CSS
JavaScript
📂 Cấu trúc thư mục
todo-list/
│
├── index.html
├── style.css
├── script.js
└── README.md

🚀 Cách chạy dự án
Bước 1: Clone project
git clone https://github.com/username/todo-list.git

Bước 2: Mở thư mục dự án
cd todo-list

Bước 3: Chạy dự án

Mở file index.html bằng trình duyệt.

Không cần cài đặt thêm thư viện nào.

🎯 Mục tiêu

Dự án này được thực hiện với mục đích:

Luyện tập HTML, CSS và JavaScript
Làm quen với Git và GitHub
Học cách viết file README.md
Làm quen với việc đưa một dự án lên GitHub
